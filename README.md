# 📊 Customer Churn Analysis & Prediction | Python & Power BI

## 📌 Project Overview
This project focuses on analyzing customer data to understand churn behavior and predict which customers are likely to leave. Python is used for data preprocessing, exploratory data analysis, and machine learning, while Power BI is used to create an interactive dashboard for business insights.

---

## 🎯 Business Objectives
- Analyze customer churn patterns  
- Identify key factors influencing churn  
- Predict customers likely to churn  
- Improve customer retention strategies  

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn)  
- Power BI  
- CSV Dataset  

---

## 📊 Python Analysis
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature engineering  
- Machine learning model (Logistic Regression / Random Forest)  
- Churn prediction  

---

## 📈 Power BI Dashboard
- Churn Rate Overview  
- Customer Segmentation  
- Churn by Contract Type  
- Churn by Payment Method  
- Monthly Charges vs Churn  
- High-Risk Customers Identification  

---

## 🔍 Key Insights
- Customers with month-to-month contracts have higher churn rates  
- Higher monthly charges lead to increased churn probability  
- Certain payment methods show higher churn behavior  
- Long-term customers are less likely to churn  

---

## 🚀 Conclusion
This project demonstrates the ability to combine data analysis, machine learning, and visualization to solve real-world business problems. It highlights strong skills in Python and Power BI for data-driven decision making.
